PerfGym Architecture: Autonomous Code Optimization Harness

Complete closed-loop system connecting AI coding agents to AST linters, deterministic profilers, and git-worktree sandboxes

Architecture Blueprint v1.0
1. Git-Worktree Sandboxing All mutations execute in dedicated worktrees (`.perfgym/worktree/*`). The main working directory and current commit remain untouched until an optimization is proven faster with 100% green tests.
2. ast-grep Structural Rules Language-agnostic AST linters prevent agents from introducing known anti-patterns (e.g. serial awaits inside loops, blocking main-thread dispatches, unindexed collection scans).
3. Closed-Loop Hill Climbing The fitness function gives the agent an explicit mathematical gradient ($\Delta\text{Metric} - \text{Penalties}$) rather than noisy pass/fail strings, eliminating optimization hallucinations.
